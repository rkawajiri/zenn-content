title: "ガントチャートで計画を見る"
---

この章のゴール: Community Edition で使えるガントチャート(Demand Gantt report)で、1 件の受注が納品されるまでの全工程を時間軸で追えるようになる。

:::message
**この章で学べる計画の考え方**

- 受注 1 件の供給の連鎖を、時間軸で見る（購買 → 製造 → 配送 → 納品）
- 深さ（depth）は、納品からどれだけ上流にさかのぼった工程かを表す
:::

:::message alert
ドラッグ操作で計画を編集できる対話的なガントチャート(**Plan editor**)は、Enterprise / Cloud Edition 限定です(公式ドキュメント `user-interface/plan-analysis/plan-editor`)。この章では、Community でも使える **閲覧専用** のガントチャートを扱います。
:::

## Demand Gantt report とは

受注 1 件について、その受注を満たすためのすべての活動(原材料の購買、拠点間の輸送、製造、最後の納品)を 1 つのガントチャートに並べて表示するレポートです(公式ドキュメント `user-interface/plan-analysis/demand-gantt-report`)。画面のタイトルは「Sales order Demand 07: Plan」のように、受注名に「: Plan」が付きます。

- 灰色（暗い色）の縦線: 現在日(計画基準日)
- 赤い縦線: その受注の納期

納期の赤い線よりも右に納品(DLVR)のバーがあれば、その受注は **遅れて** います。

![Demand Gantt report（Demand 07 の Plan タブ）。左の表が活動、右が時間軸](/images/frepple-tutorial-ja/demand-gantt.jpg)

## 開き方

1. Sales メニューの **Sales orders** を開き、受注(たとえば `Demand 07`)の詳細画面を開く。詳細画面の URL は `/detail/input/demand/<受注名>/` です。一覧の受注名のセルにこのリンクがありますが、手元の自動操作では、名前の横の ▸ マークをクリックしても画面が遷移しませんでした。開けないときは URL を直接入力してください。
2. 画面右上のタブに「Edit / Supply path / Why short or late? / **Plan** / Messages」が並ぶので、**Plan** を選ぶ。

「Why short or late?」タブは、06 章の constraint report をその受注だけに絞ったものです。「Supply path」は 05 章の供給経路です。

URL で直接開くこともできます。受注の名前の空白は `%20` にします。

```
http://localhost:9000/demandpegging/Demand%2007/
```

## 表の列の意味

ガントチャートの左側の表には、活動ごとの詳細が出ます。

| 列 | 意味 |
|---|---|
| depth | 供給経路上の深さ。0 が納品で、部品表や配送の階層が 1 つ深くなるごとに増える |
| operation | 計画された工程 |
| type | MO(製造)、DO(配送)、PO(購買)、STCK(在庫)、DLVR(納品) |
| item | その工程が作る品目 |
| resource | 使われるリソース |
| quantity required | この受注に割り当てられた数量 |
| quantity confirmed | すでに approved / confirmed / completed になっている数量 |
| quantity proposed | まだ proposed の数量(未着手の提案) |

## 読んでみよう

制約あり計画(06 章)を実行した状態で、次の 3 件を見比べます。

1. **納期が近く、遅れそうな受注**: `Demand 07`(基準日の翌日が納期。手元では納品が約 2 か月後に出ました)
2. **納期に余裕のある受注**: `Demand 05`(納期は約 3 か月先)
3. **工程の多い受注**: varnished chair の受注(`Demand 12`)。ニス塗り → 乾燥の工程が入ります

それぞれについて、次を確認してください。

- 最後の納品(DLVR)のバーは、赤い納期線の左か右か。
- いちばん時間がかかっているのは、どの工程か(購買のリードタイムか、製造か)。
- 黒い線(現在日)より左にバーはないか。制約あり計画では、過去のオーダーは confirmed のものだけのはずです。
- 部品の調達が間に合わず、製造が待たされていないか(バーの間が空いている)。

## リソースの負荷をガントで見る

リソースの側から見たいときは、次の 2 つを使います。

- **resource report**(`/resource/`): 期間別の負荷率(05 章)。
- **Resource detail**(Capacity メニュー、`/data/input/operationplanresource/`):リソースごとに、どのオーダーがいつ載っているかを一覧で見られます。

ガントチャートではありませんが、「この機械が、いつ、どの製造オーダーで埋まっているか」を時系列で読み取れます。10 章と 11 章では、この画面を使って結果を比較します。

## Enterprise の Plan editor でできること(参考)

Enterprise / Cloud Edition では、Manufacturing メニューの Plan editor で、リソース・受注・品目ごとのガントチャートが開き、次のことができます。

- バーをドラッグして、製造オーダーの開始・終了を変更する。
- 代替工程・代替リソースを選び直す。
- いずれの変更でも、frePPLe が計画が実行可能なままになるよう再計算する。

Community では使えないので、ドラッグでの調整は、11 章のように、外部の最適化ツールで代替するのが 1 つの方法です。

## つまずきポイント

- URL で開くと 404 になる、または空になる: 受注の名前が正しいか、空白を `%20` にしたかを確認してください。計画を実行していない場合も、ガントは空になります。
- 赤い線と黒い線が画面に出ない: 表示期間の外です。画面上部の期間を、計画基準日（今日）を含むようにしてください。
- 時間軸が細かすぎて読めない: 画面の時間バケット(日・週など)の設定を変えてください。
